Tara Glover | Portfolio & Consulting Website

This repository holds the source code for my professional portfolio and consulting website.

I help agencies and tech teams untangle the messy stuff. This site serves as my digital home base, outlining my fractional operations leadership, workflow design, and PM coaching services. It is built with pragmatism, human-centered design, and absolutely zero corporate fluff.

What's Inside

The site is structured around the core ways I help teams and individuals work better together:

Fractional Leadership: Embedded operations support to clear bottlenecks and build sustainable operating rhythms.

The Delivery Playbook: Diagnostics to figure out what is actually broken before we try to fix it.

Workflow Design & Tool Setup: Tailoring Jira, automations, and workflows to fit the humans actually using them.

PM Coaching: Practical, BS-free coaching for project managers and leaders navigating the messy realities of tech.

Selected Outcomes: Real-world examples of how I've scaled operations, sped up deployments, and built systems out of chaos for organizations like Georgetown University and Palantir.
